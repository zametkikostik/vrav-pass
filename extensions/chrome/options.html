Vrav Pass Settings

Desktop native host

On desktop, the extension can talk to com.vravpass.host. Install host first — see docs/DESKTOP_HOST.md

Import items (JSON)

Paste JSON array of password items, set password, click Import & Lock.

How to sync with mobile

  1. On phone: unlock Vrav Pass → Sync → Export / WebDAV / Google Drive.
  2. Extension local cache: import JSON (temporary bridge).
  3. Desktop: Native Messaging host for live vault access.
