Vrav Pass Settings

Import a vault JSON (array of items) and lock it with a password for this browser. For full mobile parity, use the same items exported from the app after unlock (temporary JSON bridge until Argon2 WASM matches mobile KDF).

Import items (JSON)

Paste JSON array of password items, set password, click Import & Lock.

How to sync with mobile

  1. On phone: unlock Vrav Pass → Sync → Export encrypted file (or WebDAV).
  2. On second device / this browser: same master password in mobile app is source of truth.
  3. Extension uses its own PBKDF2-locked cache for autofill speed (session-unlocked).
  4. Native Messaging (desktop) will connect Flutter host directly in a later version.
