# Vrav Pass — Mobile (Flutter)

## Bootstrap (first time)

The repository contains the Dart/Flutter source, but the platform folders (`android/`, `ios/`…) are generated by Flutter.

```bash
cd mobile
flutter create . --org com.vravpass --project-name vrav_pass
flutter pub get
```

This will generate the missing platform code without overwriting existing `lib/` and `pubspec.yaml`.

## Run

```bash
flutter run
```

## Build APK locally

```bash
flutter build apk --release --split-per-abi
```

Artifacts appear in `build/app/outputs/flutter-apk/`.

## CI

GitHub Actions workflow (`.github/workflows/build-apk.yml`) automatically builds the APK on every push to `main`.

> Note: After the first `flutter create .` is committed, the CI will be able to build successfully.
